# 증빙 자료 (캡처 · 영상)

| 폴더 | 넣는 것 | 담당 | Git |
|---|---|---|---|
| `program/` | 프로그램 실행 화면 캡처 2~3장, 시연 영상(Load → 수정 → 저장 → Reload → Validation) | 김동훈 | 캡처는 올라감, 영상 파일은 올라가지 않음 |
| `실행결과/` | 프로그램(`final_evidence.py`, `build_final.py`)을 실행한 터미널 화면 캡처 — 폴더 구조·이미지 수량(900)·TXT 수량(900)·짝·Validation. 실제 사진 이름이 화면에 나오지 않게 찍는다 | 손상우 | **올라감** |
| `final/` | `data/final` 폴더 구조·이미지 수량(900)·TXT 수량(900) 캡처, 대표 검수 완료 이미지 3~5장, 대표 라벨 | 손상우 | **올라가지 않음** (실제 사진이 나옴) |

- `program/` 의 캡처와 영상은 **가짜 샘플 사진**으로 찍습니다. 실제 회사 사진이 보이는 화면은 공개 저장소에 올리지 않습니다.
- `final/` 은 실제 데이터가 나오므로 `.gitignore` 로 제외합니다. 제출 방식에 맞춰 별도로 전달합니다.
