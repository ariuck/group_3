### 테스트 데이터
- 대상 이미지: 실제 4K 조각김치 이미지 20장

## 2. Pilot Test (실제 작업 흐름 안정성 검증)

### 테스트 목적
연속 작업 환경에서 발생할 수 있는 잠재적 결함(좌표 오차, 빈 라벨 예외, 저장 누락 등)을 사전에 도출하고 조치하기 위해 50장 규모로 시범 작업을 수행합니다.

### 테스트 데이터
- 대상 이미지: 실제 조각김치 이미지 50장
- 대상 라벨: 대응하는 YOLO TXT 50개

### 1차 시험 결과
- **정상 통과**: 47장 (PASS)
- **결함 발견**: 3장 (FAIL)

### 발견된 문제 및 조치 내역 (Defect Log)

#### 🔴 FAIL-01: BBox 수정 후 재로딩 시 이전 위치 복원 결함
* **발생 현상**: BBox 크기를 수정한 뒤 `[저장]`을 눌렀으나, 이미지를 다시 열었을 때 수정 전 위치로 복원됨.
* **원인 분석**: BBox 편집 상태 플래그(`is_dirty`)가 좌표 저장 배열에 즉시 반영되지 않고 이전 캐시 좌표를 저장함.
* **조치 내용**: BBox 핸들 드래그 종료 시 원본 픽셀 좌표를 즉시 재계산하여 상태 배열을 갱신하도록 수정.
* **재시험 결과**: **PASS (정상 복원 확인)**

#### 🔴 FAIL-02: Zoom 확대 상태에서 새 BBox 생성 시 좌표 틀어짐
* **발생 현상**: 4K 이미지를 2배 이상 확대한 상태에서 마우스로 새 BBox 를 그리면 저장 후 실제 위치가 밀려남.
* **원인 분석**: 마우스 클릭 좌표(Canvas Pixel)를 원본 이미지 좌표(Image Pixel)로 역변환할 때 Zoom 배율(`scale`) 및 이동 오프셋(`offset_x, offset_y`)이 누락됨.
* **조치 내용**: 캔버스 좌표 역변환 함수 `(canvas_x - offset_x) / scale` 공식 적용.
* **재시험 결과**: **PASS (배율 300% 상태에서도 오차 0px 달성)**

#### 🔴 FAIL-03: 정상 김치의 빈 TXT 파일에 대한 검증 오류
* **발생 현상**: 검출 대상 이물이 없는 정상 김치 이미지의 빈 TXT 파일(0 바이트)을 Validation 에서 `CRITICAL: 빈 파일 오류`로 처리함.
* **원인 분석**: 객체가 없는 정상 이미지(Negative Sample)의 정상적인 빈 라벨을 비정상 파일로 오인.
* **조치 내용**: 빈 TXT 는 오류(`CRITICAL`)가 아닌 확인용 안내(`INFO: EMPTY_LABEL`)로 심각도 조정.
* **재시험 결과**: **PASS**

**Pilot Test 최종 판정**: 결함 3건 조치 완료 후 **50 / 50 PASS (통과)**

## 3. Final Acceptance Test (최종 인수 검증 기준)

900장 전체 라벨링 검수 완료 후 본 프로젝트의 산출물이 교과 8로 인계 가능한지 확인하는 최종 검증 기준입니다.

### 필수 통과 기준
1. **900장 Pair 무결성**: 900장 이미지와 900개 TXT 파일명이 1:1 로 완벽히 일치해야 함.
2. **치명적 오류(Critical Error) 0건**: Class ID 초과, 좌표 0~1 초과, 이미지 경계 이탈 0건.
3. **미처리 REVIEW 0건**: 교차 검수를 통해 모든 애매한 데이터의 최종 판단 완료.
4. **Validation 오류 0건**: 자동 검증 도구 실행 시 FAIL 0건 달성.

### 검증 결과
- 전체 검사 대상: 900장
- 치명적 오류(CRITICAL): **0건**
- 미해결 이슈(UNRESOLVED REVIEW): **0건**
- 자동 검증 결함: **0건**

**최종 판정**: **ACCEPTED (인수 승인)**
