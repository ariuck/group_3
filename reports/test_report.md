## 2. Pilot Test (실제 작업 흐름 안정성 검증)

### 목적
연속 작업 환경에서 생길 수 있는 결함(좌표 오차, 빈 라벨 예외, 저장 누락 등)을 본 작업 전에 찾아 조치합니다. 사람이 실제 작업 순서(열기 → 수정 → 저장 후 다음 → 검수 상태 입력)로 **20~50장**을 처리합니다.

### 현재 상태: **진행 전** (시험 후 결과를 기록해 반영)
초안에 정리된 시범 작업 결과("50장, 47 PASS + 3 FAIL → 조치 후 50/50 PASS")는 일시·데이터·시험자 기록을 보완한 뒤 **정식 결과로 확정**합니다. 그 전까지는 아래 결함 3건을 *보고된 내용*으로 두고, 현재 코드에서 같은 문제가 다시 나타나지 않는지만 확인했습니다.

| 보고된 결함 | 현재 코드 확인 |
|---|---|
| FAIL-01: BBox 수정 후 저장했는데 다시 열면 수정 전 위치로 복원 | 실데이터 Round-trip 900/900, 편집 후 저장·복원 자동 시험 통과 |
| FAIL-02: Zoom 확대 상태에서 새 BBox 를 그리면 저장 위치가 밀림 (역변환에 scale·offset 누락) | `test_viewport.py` 의 좌표 왕복·확대와 무관한 저장 좌표 시험 통과 |

## 2-1. 검수 작업 중 발견한 오류와 수정 (4일차)

900장을 실제로 검수하면서 팀원 PC 6대의 결과를 합치는 과정에서 찾은 문제입니다. 모두 고친 뒤 해당 시험(`tests/`)과 전체 시험을 다시 돌려 통과했습니다.

| 발견한 문제 | 원인 | 수정 | 재시험 |
|---|---|---|---|
| 검수표를 합치면 출처가 잘못 적힌 401줄이 조용히 빠짐 | 출처 데이터셋·split 이 비어 있거나 잘못된 줄을 키로 못 찾음 | 원본 폴더의 이름으로 출처를 바로잡고, 못 찾은 줄이 있으면 저장을 막음 (`merge_manifests.py`) | `test_merge_manifests.py` 통과 |
| 검수자가 원본 라벨을 보고 있었음 | 라벨 가져오기가 내용이 다른 기존 라벨을 건너뜀 | `--overwrite` 와 자동 백업, 건너뛴 경우 경고 추가 (`import_labels.py`) | `test_import_labels.py` 통과 |
| 이미지 유형이 비어 있어도 `Enter` 로 다음 사진으로 넘어감 | 검수 기록 필수 칸 검사 없음 | 이미지 유형이 비면 저장·이동을 막음 | `test_quick_review.py` 통과 |
| Windows 에서 `Zone.Identifier` 파일이 라벨 폴더에 섞여 들어옴 | 압축 해제·복사 때 생기는 표시 파일 | 프로그램 시작 시 자동 정리, 묶기에서 제외 | `test_data_paths.py`, `test_pack_results.py` 통과 |
| 공유 페이지에서 "여기에 놓으면 바로 올라갑니다" 안내가 사라지지 않음 | 화면 전체 끌어놓기 처리 | 영역 안에서만 처리하도록 변경 (`share_server.py`) | `test_share_server.py` 통과 |
| 같은 파일 이름 검수표가 겹쳐 덮어써짐 | 사람마다 같은 이름의 CSV 를 올림 | 묶을 때 이름·번호 범위를 붙임 (`pack_results.py --name --from --to`) | `test_pack_results.py` 통과 |
| 최종 확인 중 너무 작은 BBox(9×12px) 경고 1건 | 형태를 알 수 없는 점에 박스를 그림 | 검수자가 확인하고 삭제 (BBox 기준서 §4) | Validation 경고 0건 |
