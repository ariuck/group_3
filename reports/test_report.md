## 2. Pilot Test (실제 작업 흐름 안정성 검증)

### 목적
연속 작업 환경에서 생길 수 있는 결함(좌표 오차, 빈 라벨 예외, 저장 누락 등)을 본 작업 전에 찾아 조치합니다. 사람이 실제 작업 순서(열기 → 수정 → 저장 후 다음 → 검수 상태 입력)로 **20~50장**을 처리합니다.

### 현재 상태: 별도 시범 없이 본 작업에서 병행
초안에 정리된 시범 작업 결과("50장, 47 PASS + 3 FAIL → 조치 후 50/50 PASS")는 일시·데이터·시험자 기록이 없어 정식 결과로 쓰지 않습니다. 대신 아래 결함 3건을 *보고된 내용*으로 두고, 현재 코드에서 같은 문제가 다시 나타나지 않는지 확인했습니다.

| 보고된 결함 | 현재 코드 확인 |
|---|---|
| FAIL-01: BBox 수정 후 저장했는데 다시 열면 수정 전 위치로 복원 | 실데이터 Round-trip 900/900, 편집 후 저장·복원 자동 시험 통과, 사람 확인 §1-1(2) |
| FAIL-02: Zoom 확대 상태에서 새 BBox 를 그리면 저장 위치가 밀림 (역변환에 scale·offset 누락) | `test_viewport.py` 의 좌표 왕복·확대와 무관한 저장 좌표 시험 통과, **사람 확인 §1-1(2) 300% 확대 BBox 복원 PASS** |
| FAIL-03: 정상 김치의 빈 TXT 를 `CRITICAL` 로 처리 | `validate_rows` 가 빈 TXT 를 `INFO: EMPTY_LABEL` 로 처리, `test_validator.py::test_empty_label_info` 통과 |

### Pilot Test 기록

| 항목 | 기록 |
|---|---|
| 방식 | 별도의 20~50장 시범 없이, 본 작업(900장 교차검수)에서 같은 작업 흐름(열기 → 수정 → 저장 후 다음 → 검수 상태 입력)으로 사용 |
| 처리 장수 | 900장 전수 (검수 완료 674 · 수정 완료 226) |
| 평균 처리 시간 | 측정하지 않음 |
| 발견한 결함 | 2-1 과 [이슈 기록](../docs/records/이슈기록.md) 에 정리. 모두 해결했고 열린 결함은 0건 |
| 기록 확인 | 2026-10-08, 강동연 |

**Pilot Test 판정**: 별도의 20~50장 시범 기록은 남아 있지 않습니다. 900장 검수가 이 프로그램으로 그대로 진행되어 끝났고, 그 결과는 위 Final Acceptance 로 확인했습니다.
