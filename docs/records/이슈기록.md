## 4일차 (검수와 결과 합치기)

| 문제 | 원인 | 해결 | 재확인 |
|---|---|---|---|
| 검수표를 합치면 출처가 잘못 적힌 401줄이 조용히 빠짐 | 출처 데이터셋·split 이 비거나 틀린 줄을 키로 찾지 못함 | 원본 폴더의 이름으로 출처를 바로잡고, 못 찾은 줄이 있으면 저장을 막음 | `test_merge_manifests.py` |
| 검수자가 원본 라벨을 보고 있었음 | 라벨 가져오기가 내용이 다른 기존 라벨을 건너뜀 | `--overwrite` 와 자동 백업, 건너뛴 경우 경고 | `test_import_labels.py` |
| 일부 PC 에서 올라온 라벨이 원본 그대로였음 | 그 PC 에 최신 라벨이 아니라 원본 복사본이 있었음 | 검수표는 정상이었으므로 올라온 라벨을 확인해 해당 구간 라벨을 교체하고 전체본을 다시 만들어 배포 | 같은 번호 라벨 비교 |
| 한 팀원의 2차 zip 이 1~350번을 담고 있었고, 301~350번은 검수자 칸이 빈 아직 검수 전인 줄이었음 | zip 에 맡은 범위(1~300) 밖의 번호가 함께 들어 있었음 | 각자 맡은 번호 범위만 골라서 가져오고 합침 | 범위별 상태 집계 |
| 이미지 유형을 비워 둔 채 `Enter` 로 다음 사진으로 넘어갈 수 있음 (개선 요청) | 필수 칸 검사가 없었음 | 이미지 유형이 비면 `Enter` 와 검수 기록 저장을 막음 | `test_quick_review.py` |
| Windows 의 `Zone.Identifier` 파일이 라벨 폴더에 섞여 들어옴 | 압축 해제·복사 때 생기는 표시 파일 | 프로그램 시작 시 자동 정리, 묶기에서 제외 | `test_data_paths.py` · `test_pack_results.py` |
| 여러 사람의 검수표(CSV)가 같은 이름이라 합칠 때 겹쳐 덮어써질 위험 | 각자 같은 이름으로 저장·전달함 | 묶을 때 이름·번호 범위를 붙임 (`pack_results.py --name --from --to`) | `test_pack_results.py` |
| 공유 페이지에서 끌어놓기 안내가 사라지지 않음 | 화면 전체에서 끌어놓기를 처리 | 영역 안에서만 처리 | `test_share_server.py` |
| 검수표 CSV 가 커밋에 들어감 | 실제 사진 파일명이 든 검수표를 추적함 | 푸시 전 이력에서 제거, `.gitignore` 에 추가 | `git ls-files` 에 CSV 없음 |
| 작은 점에 BBox 를 그려 둔 것(9×12px)이 최종 확인에서 경고로 남음 | 형태를 알 수 없는 점 | 검수자가 확인하고 삭제 (BBox 기준서 §4) | Validation 경고 0건 |
