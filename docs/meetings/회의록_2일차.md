## 3. 결정한 것
- **파일 담당을 나눠 충돌을 줄인다.** 로직은 각자 파일(`navigator.py`, `viewport.py`, `manifest_writer.py`, `validator.py`)에 쓰고, 가장 충돌이 잘 나는 `main_window.py` 에는 연결 몇 줄만 추가한다.
- **만든 사람과 시험하는 사람은 다르게 한다.** ② ↔ ③, ④ ↔ ⑤ 가 서로 시험한다.
- **저장 실패하면 이동하지 않는다.** `save()` 는 성공 `True` / 실패 `False`.
- **프로그램이 만든 `reports/validation_report.csv`, 그리고 `data/` 아래 데이터는 어디에 두든 Git 에서 제외한다.** (`1d0e470`, `b37a281`)
- 오늘 하지 않는 것: BBox **이동·크기 조절**(잘못된 BBox 는 삭제 후 다시 그리기), Pilot Test, 900장 본 작업.
- 규칙: **좌표·저장 오류가 남아 있으면 900장 본 작업(4일차)을 시작하지 않는다.**

| 문제 | 해결 |
