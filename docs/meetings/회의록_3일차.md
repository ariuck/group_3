### 3-4. 렉 해결 (`9b13de9`)
방향키를 꾹 눌러 넘길 때 렉이 있었다. 하단 미리보기가 원인이었다.
- 사진 읽기를 다른 스레드에서 하고, 읽는 동안 이전 화면이 멈추지 않게 했다.
- 미리보기는 키를 놓고 0.22초 뒤에 불러온다.
- 큰 사진은 줄여서 그린다.
- 측정(개발 환경): 키 입력 지연 최대 168ms → 39ms, 중앙값 39ms → 0ms. 키를 놓은 뒤 최종 사진은 약 0.17초, 미리보기는 약 0.7초 뒤에 표시.

### 3-5. 검수표(CSV) 점검과 수정 (`7bbca75`)
상태 흐름·특수 글자·같은 이름 사진·원본 라벨 없는 사진은 정상이었고, 허점 3가지를 고쳤다.
- 빈 파일(0바이트·공백 줄뿐)인 검수표가 있으면 저장이 막히던 문제 → 새 검수표로 보고 기록. 머리글이 다른 파일은 덮어쓰지 않고 안내만 함
- `검수일` 칸이 항상 비던 문제 → 상태가 검수 완료·수정 완료·수정 필요·제외가 될 때 오늘 날짜를 자동 기록(이미 적힌 날짜는 유지, `검수 전`에는 안 적음). `manifest_guide.md` 반영
- 검수표를 못 읽을 때(엑셀 cp949 저장본 등) 사진마다 경고창이 반복되던 문제 → 경고창은 한 번, 이후 이미지 위 경고 줄에 계속 표시

## 5. 시험 현황
- `tests/` 에 자동 시험 22개 파일(`day1_selftest.py` 포함). 커밋 직전 전체 통과를 확인하고 커밋했다.
- 무작위로 조작하는 시험(fuzz)에서 RAW 해시 불변, 저장 후 다시 읽기 일치, 검수표 행, 이동 번호 일치를 확인했다.
- 알려진 한계: 한글 입력 시험(`test_hangul_input`)은 WSL 환경의 창 포커스 타이밍 때문에 간헐적으로 실패하며 재시도하면 통과한다.
- 실제 데이터로 사람이 하는 시험(Golden·Pilot)의 **정식 기록은 아직 `main` 에서 확인되지 않았다** (아래 §6).
