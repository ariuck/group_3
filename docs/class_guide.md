# Class Labeling Guide

> 라벨링할 때 **"이 객체를 몇 번 Class 로 저장해야 하는가?"** 를 팀원 모두가 같은 기준으로 판단하기 위한 문서입니다.
> 초안입니다. 샘플 사진을 함께 보면서 팀이 확인하고 필요하면 고칩니다. 프로그램의 Class 설정은 `configs/classes.yaml` 입니다.

## 공통 원칙

- 사용 Class: 0~6 (번호를 바꾸지 않는다)
- 판단이 명확한 객체만 해당 Class 로 지정합니다.
- Class 판단이 어려우면 임의로 결정하지 않고 **REVIEW** 처리합니다.
- 김치 자체는 검출 대상 Class 가 아닙니다.
- Class 4 고무장갑은 현재 프로젝트에서 사용하지 않습니다.
- 정상 김치 / 김치+대상 / 대상 단독 은 **이미지 유형**(`scene_type`)이지 Class 가 아닙니다.

---

## Class 0 — 나뭇잎·종이류

### 대상
조각김치 사이에서 발견되는 나뭇잎 또는 종이 형태의 객체

### 포함
- 나뭇잎
- 잘린 잎 조각
- 종이 조각

### 제외
- 김치 잎
- 파
- 고추

### 애매한 경우
- 나뭇잎인지 김치 잎인지 명확하지 않으면 REVIEW

---

## Class 1 — 플라스틱류·돌·금속류

### 대상
플라스틱, 돌, 금속과 같이 제조 과정에서 이물로 판단되는 객체

### 포함
- 플라스틱 조각
- 돌
- 금속 조각

### 제외
- 나뭇가지
- 식물성 잎
- 파·고추

### 애매한 경우
- 재질을 이미지로 판단하기 어려우면 REVIEW

---

## Class 2 — 나뭇가지류

### 대상
막대 또는 가지 형태의 나무성 이물

### 포함
- 나뭇가지
- 작은 가지 조각
- 줄기 형태의 목질 이물

### 제외
- 파 줄기
- 고추 꼭지
- 일반 잎 조각

### 애매한 경우
- 나뭇가지와 채소 줄기의 구분이 어려우면 REVIEW

---

## Class 3 — 벌레류

### 대상
이미지에서 확인되는 벌레 또는 곤충 형태의 객체

### 포함
- 벌레
- 곤충 형태가 명확한 객체

### 제외
- 작은 검은 반점
- 김치 양념 덩어리
- 형태를 식별할 수 없는 이물

### 애매한 경우
- 벌레인지 단순 얼룩인지 판단하기 어려우면 REVIEW

---

## Class 4 — 고무장갑

### 현재 사용 여부
사용하지 않음

### 처리 기준
- 현재 교과 7 라벨링에서는 Class 4 를 새로 생성하지 않습니다. (프로그램도 새 BBox 생성을 막습니다)
- 기존 TXT 에서 Class 4 가 발견되면 임의로 삭제하지 않고 **REVIEW** 처리합니다. (검수표: 상태 `수정 필요` + `발견된 문제`에 `REVIEW: Class 4 발견`)
- 팀 기준에 따라 2명 이상 확인한 뒤 처리하고, 근거를 기록합니다.

---

## Class 5 — 병해·갈변

### 대상
식재료에서 확인되는 병해 또는 갈변 형태

### 포함
- 갈색으로 변색된 부위
- 병해로 판단되는 이상 부위

### 제외
- 정상적인 김치 양념 색상
- 그림자
- 촬영 조명에 의한 색 변화

### 애매한 경우
- 실제 갈변인지 조명 차이인지 판단하기 어려우면 REVIEW

---

## Class 6 — 파·고추

### 대상
조각김치 이미지에서 검출 대상으로 지정된 파 또는 고추

### 포함
- 파 조각
- 고추 조각

### 제외
- 김치 잎
- 나뭇잎
- 나뭇가지

### 애매한 경우
- 파·고추와 다른 식물 조각을 구분하기 어려우면 REVIEW

---

## 작업 흐름

```text
객체 발견
        ↓
이 문서에서 Class 확인
        ↓
명확함 → BBox 작성 + Class 지정
애매함 → 임의로 지정하지 않고 REVIEW → 교차검수자가 최종 확인
```

검수표에서 REVIEW 를 표시하는 방법은 [manifest_guide.md](manifest_guide.md) 를 참고합니다.
