# `tools/check_docs.py`

> 코드와 문서가 1:1로 대응하는지 점검한다. 문서가 빠진 `.py` 와, 코드가 사라졌는데 남은 `.md` 를 찾는다.

[← 코드 문서 목차](../README.md) · [코드 보기](../../../tools/check_docs.py)

## 사용법

```bash
python tools/check_docs.py
```

```
점검 완료: 코드 70개 · 문서 없음 0개 · 코드 없는 문서 0개
```

문제가 있으면 목록을 보여 주고 **종료 코드 1** 을 돌려준다. 커밋 전에 돌리면 된다.

## 규칙

- `<경로>/<이름>.py` → `docs/code/<경로>/<이름>.md`
- 내용이 없는 `__init__.py` 는 문서를 만들지 않는다.
- `docs/code/README.md`(목차)는 검사에서 뺀다.

## 주요 구성요소

| 이름 | 설명 |
|---|---|
| `DOCS` | `docs/code` |
| `SKIP_DIRS` | 점검하지 않는 폴더: `.git`, `.venv`, `venv`, `__pycache__`, `.pytest_cache`, `data`, `docs`, `.vscode`, `.idea` |
| `code_files(root)` | 문서가 있어야 하는 `.py` 상대 경로 |
| `check(root, docs)` | `(코드 목록, 문서 없음, 코드 없는 문서)` |
| `main()` | 결과 출력, 종료 코드 반환 |

## 의존성

- **사용하는 것**: 표준 라이브러리 `pathlib`, `sys`
- **사용하는 곳**: 직접 실행

## 주의사항

- 파일이 **있는지만** 본다. 문서 내용이 코드와 맞는지는 사람이 확인해야 한다.
- 코드 파일 이름을 바꾸거나 옮기면 문서도 같은 경로로 옮겨야 "문서 없음 1 + 코드 없는 문서 1" 이 사라진다.
