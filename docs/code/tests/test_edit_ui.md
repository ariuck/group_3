[← 코드 문서 목차](../README.md) · [코드 보기](../../../tests/test_edit_ui.py) · 대상: [`src/ui/main_window`](../src/ui/main_window.md)

```bash
python -m unittest tests/test_edit_ui.py      # 화면(Tk) 필요
```

## 시험 내용 (`EditUiTest`)

| 묶음 | 확인하는 것 |
|---|---|
| 표시 | 선택한 BBox 에만 핸들 · 좌표줄이 선택·드래그를 따라감 · 배율 % 표시 · 도구 줄에 주요 버튼 |
| 화면 보정 | 밝기·대비·흑백은 사본에만 적용 · 버튼이 단계 순환 후 원래대로 · **사진과 저장 라벨은 절대 안 바뀜** |
| 십자선 | 켰을 때만 따라다님 · 드래그 중 유지 · 끄면 사라짐 |
| 키보드 | `Tab` 순환 · BBox 없을 때 `Tab` 무해 · `Shift+방향키` 1px / `Ctrl+Shift` 10px · 연속 이동은 Undo 한 번 · 잠깐 쉬면 새 Undo 단계 · 가장자리·선택 없음에서 멈춤 · `H` 로 숨기면 편집 막힘 · 키 연결 확인 |
| 라벨 목록 | 원본/변경 표시 · 옮기거나 새로 만든 BBox 는 변경 · 줄 클릭 = 선택 · 표 갱신 시 선택 되먹임 없음 · 빈 표 |
| 이동 모드 | 왼쪽 버튼으로 화면 이동 · 다시 끌 수 있음 |
| 저장+다음 | 저장 후 이동 · 마지막 사진은 저장만 · 저장 실패 시 이동 안 함 |
| Diff | 기본 꺼짐 · 변화 없음 · 수정(원래 위치 표시) · 추가/삭제 · 원본 라벨 없는 사진 · 끄면 표시 지움 |
| 전체 삭제 | 확인 후 Undo 가능 · 거절 가능 · BBox 없으면 묻지 않음 |
| 마우스 편집 | 클릭은 선택만 · 안쪽 드래그 = 이동 · 이동 Undo/Redo · 가장자리에서 멈춤 · 핸들 크기 조절 · 선택 없으면 핸들 무시 · 빈 곳 드래그 = 새 BBox · `Shift`+드래그 = 겹쳐서 새 BBox · `Esc` 로 이동/새 BBox 취소 후 선택 해제 · 살짝 흔들림은 이동 아님 · 드래그 중 Undo 무시 · 저장 파일에 옮긴 위치 |
