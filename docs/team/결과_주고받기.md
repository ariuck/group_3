# 결과 주고받기 (같은 와이파이·랜 안에서)

USB 없이 라벨(txt)과 검수표(csv)를 PM PC 와 검수자 PC 사이에서 주고받는 방법입니다. PM PC 가 잠깐 서버를 켜고, 다른 PC 는 **브라우저로 내려받기·올리기**만 합니다. 인터넷을 거치지 않고, 계정이나 암호 설정이 필요 없습니다.

> 라벨과 검수표는 사진 파일명이 들어 있는 회사 데이터입니다. **필요한 사람이 모두 받으면 바로 서버를 끄세요.**

## PM: 서버 켜기 (처음 한 번 준비)

**1. 방화벽 규칙 추가** (PM PC 에서 한 번만, 관리자 PowerShell)
```powershell
New-NetFirewallRule -DisplayName "라벨공유 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
```
개인 네트워크에서 8000 포트만 엽니다. 다 끝나면 `Remove-NetFirewallRule -DisplayName "라벨공유 8000"` 로 지웁니다.

**2. 보낼 파일 만들기** (WSL, 프로젝트 폴더)
```bash
python tools/pack_results.py
```
`data/share/결과_날짜_시각.zip` 이 만들어집니다. (검수자에게 나눠 줄 합친 결과)

**3. `공유시작.bat` 더블클릭**
- 가장 최근 zip 을 `C:\공유\보내기` 에 복사하고 서버를 켭니다.
- 검은 창에 **접속 주소**(예: `http://192.168.40.98:8000`)와 **4자리 접속 번호**가 나옵니다. 이 둘을 검수자에게 알려 줍니다.
- 방화벽 창이 뜨면 **개인 네트워크**만 허용합니다.

## 검수자: 내려받기와 올리기 (브라우저만)

1. 브라우저 주소창에 PM 이 알려 준 주소를 입력합니다.
2. **4자리 번호**를 입력하고 확인을 누릅니다.
3. **내려받기**: 목록의 zip 을 클릭합니다. 풀어서 라벨을 가져옵니다. ([라벨 합치기](라벨_합치기.md))
4. 검수를 끝낸 뒤 **올리기**: WSL 에서 자기 범위를 묶고,
   ```bash
   python tools/pack_results.py --name 김동훈 --from 1 --to 300
   ```
   브라우저의 **올리기** 칸에서 `data/share/결과_김동훈_….zip` 을 골라 올립니다. (탐색기 주소창에 `\\wsl$\Ubuntu\home\<사용자>\group_3\data\share` 를 붙여넣으면 파일이 보입니다)
5. "받았습니다: … (라벨 300개, 검수표 300줄)" 가 나오면 끝입니다.

## PM: 받은 결과 합치기

올라온 zip 은 `C:\공유\받은결과` 에 저장되고, 안의 라벨과 검수표는 **`C:\공유\받은결과\풀림`** 에 자동으로 풀립니다. 직접 풀 필요가 없습니다. WSL 에서:

```bash
python tools/import_labels.py /mnt/c/공유/받은결과/풀림 --apply --overwrite     # 검수하며 고친 라벨 반영
python tools/merge_manifests.py /mnt/c/공유/받은결과/풀림 --apply              # 검수표 합치기 (내 검수표와 자동으로 함께)
```

세 명이 올린 결과를 한 번에 합칩니다. 이름이 사람마다 달라서 겹치지 않습니다. 합친 뒤 확인할 것은 [검수 배정](검수_배정.md) 을 보세요.

## 안전장치

| 장치 | 내용 |
|---|---|
| 접속 번호 | 4자리 번호를 모르면 목록·내려받기·올리기가 모두 거부됩니다. 여러 번 틀리면 1분간 잠깁니다. |
| 같은 네트워크만 | 사설망(192.168.x.x, 10.x.x.x 등)의 PC 만 접속할 수 있습니다. |
| 올릴 수 있는 것 | **라벨(.txt)과 검수표(.csv)만 든 zip** 뿐입니다. 사진·프로그램 파일·폴더를 벗어나는 경로·너무 큰 파일은 거부합니다. |
| 덮어쓰기 없음 | 같은 이름이 있으면 이름 뒤에 시각을 붙여 따로 저장합니다. |
| 자동 종료 | 켠 지 120분이 지나면 저절로 꺼집니다. |
| 공유 범위 | `C:\공유` 폴더 안의 `보내기`(내려받기용)와 `받은결과`(올린 것)만 쓰고, 다른 폴더에는 접근하지 않습니다. |

## 안 될 때

- **타임아웃**: PM PC 의 방화벽 규칙(위 1번)이 개인 네트워크용으로 들어갔는지 확인하세요.
- **번호가 틀렸다고 나옴**: 검은 창에 표시된 4자리 번호를 다시 확인하세요. 서버를 다시 켜면 번호가 새로 정해집니다.
- **올리기가 거부됨**: 화면에 이유가 나옵니다. `--name`·`--from/--to` 로 묶은 zip 인지, 사진(jpg)이 섞이지 않았는지 확인하세요.
- **접속이 안 됨**: 두 PC 가 같은 공유기에 연결되어 있는지(IP 앞부분이 같은지) 확인하세요.
- 서버 창을 닫으면 바로 멈춥니다. 한 번 끈 뒤 다시 켜면 접속 번호가 바뀝니다.
