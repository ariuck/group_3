# 검수 배정 (교차검수 3명)

900장을 이후영 · 지혜성 · 김동훈 3명이 나눠 검수합니다. **작성자와 검수자는 달라야 한다**는 규칙을 지키도록, 3명 모두 **자기가 작성한 사진이 하나도 없는 범위**로 나눴습니다.

번호는 프로그램 화면의 `N / 900` 과 같습니다. (데이터셋 → split → 파일명 순) 시작 번호로는 `Ctrl+G` 로 바로 이동합니다.

## 배정

| 검수자 | 검수할 번호 | 장수 | 위치 | 작성자 (이 범위의 원래 작업자) |
|---|---|---:|---|---|
| **김동훈** | 1 ~ 300 | 300 | 학습데이터1 / train | 이후영 120 · 손상우 128 · 강동연 52 |
| **이후영** | 301 ~ 600 | 300 | 학습데이터1 / train 200 + 학습데이터2 / train 100 | 손상우 60 · 지혜성 140 · 김석범 100 |
| **지혜성** | 601 ~ 900 | 300 | 학습데이터2 / train 120 + validation 180 | 김석범 120 · 김동훈 180 |

- 3명 모두 300장씩이고, 범위가 겹치지 않으며, 1~900 전체가 빠짐없이 들어갑니다.
- 각자 자기 번호 범위 **한 덩어리**만 보면 됩니다.
- 2026-10-07 합친 검수표(작성자 칸 정리 후) 기준으로 확인한 배정입니다. 작성자 칸이 바뀌면 다시 확인하세요.

## 검수하는 방법

1. 프로그램을 켜고 **검수자 칸에 자기 이름을 한 번** 씁니다. 다음 사진부터는 빈 칸에 자동으로 채워집니다. (프로그램을 켜 둔 동안만 기억)
2. `Ctrl+G` 로 자기 시작 번호(김동훈 1, 이후영 301, 지혜성 601)로 이동합니다.
3. 한 장씩 보고 판단합니다.
   - **맞다** → `Enter` (저장하고 다음 사진)
   - **틀렸다** → BBox 를 고치고 `Enter`
   - **애매하다** → `R` 을 눌러 이유를 쓰고 `Enter` (`REVIEW: 이유 코드`, [BBox 기준서](../standards/bbox_guide.md)·[Class 기준서](../standards/class_guide.md) 참고)
4. 자기 번호 범위의 **끝 번호에 도달하면 멈춥니다.** 범위 밖 사진은 열어 보기만 하고 저장하지 마세요.

## 지켜야 할 것

- **자기 범위만 저장하세요.** 모두가 같은 합친 결과에서 시작해서 자기 범위만 바꿔야, 나중에 결과를 합칠 때 서로 덮어쓰지 않습니다.
- **검수 완료 표시는 검수자 칸입니다.** `Enter` 를 누르면 원본과 달라진 사진은 `수정 완료` 로 기록되므로(작성자가 이미 고친 사진 포함), 검수를 마쳤는지는 **검수자 칸에 이름이 있는지**로 확인합니다.
- 검수하지 않고 넘기기만 한 사진은 저장되지 않아서 검수자 이름이 기록되지 않습니다. `W` 나 `Ctrl+S` 로 저장만 해도 이름이 들어가니, **검수를 마친 사진에만 저장**하세요.
- 데이터(txt·검수표)는 **허용된 방법**(USB 등)으로만 주고받습니다. ([라벨 합치기](라벨_합치기.md))

## 시작하기 전 (각자)

합친 결과를 받아서 내 PC 에 넣습니다.

```bash
python tools/import_labels.py 받은폴더 --apply        # 라벨(txt) 가져오기
```

받은 `dataset_manifest.csv` 로 내 `manifests/dataset_manifest.csv` 를 바꿉니다. (바꾸기 전에 내 파일을 따로 복사해 두세요)

## 끝난 뒤 (결과 모으기)

각자 `data/work/` 의 txt 와 `manifests/dataset_manifest.csv` 를 PM 에게 전달해서 합칩니다.

```bash
python tools/import_labels.py data/inbox_labels --apply --overwrite
python tools/merge_manifests.py data/inbox --apply
```

합친 뒤 확인할 것: 검수자 칸이 900줄 모두 채워졌는가, 작성자와 검수자가 같은 줄이 0인가, 미처리 REVIEW 가 0인가, Validation 오류가 0인가.
