# 2. Class / BBox 기준 정리

> **이 문서는 두 기준서로 통합되었습니다.** 같은 내용을 일차별 문서에 따로 두면 수정할 때 어긋나기 때문에, 기준은 아래 한 곳에서만 고칩니다.

| 알고 싶은 것 | 보는 곳 |
|---|---|
| Class 번호와 뜻, 어떤 Class 인지 정하는 법, 애매할 때 구분하는 기준, 이미지 유형별 처리, REVIEW 조건 | [Class 기준서](../../../class_guide.md) |
| BBox 를 어디까지 그리는지(여백 허용치, Class 별 기준, 갈변 그리는 법), 좌표 형식, 검수 상태 | [BBox 기준서](../../../bbox_guide.md) |
| 검수표(CSV) 작성 방법, REVIEW 이유 코드 | [검수표 작성 가이드](../../../manifest_guide.md) |
| 팀 전체 운영 기준 (데이터, 역할, Git, 완료 기준) | [Project Baseline](../../../project_baseline.md) |

1일차에 이 문서에 있던 Class 표, BBox 5가지 약속, 검수 상태, 이미지 유형별 처리, 좌표 형식, `【합의】` 3가지(여백·가장자리·최소 크기)는 모두 위 기준서에 확정된 내용으로 들어 있습니다.
