# 4. 기능 목록 및 화면 설계

> **"내일 만들 프로그램이 무엇을 할 수 있어야 하는가"** 를 정한 설계입니다.
> 처음부터 다 만들지 않고 **꼭 필요한 것(Must Have)부터** 만들고 나머지는 나중으로 미룹니다.
> 더 자세한 표: [Must Have 기능 목록](필수기능목록.md) · 의사 코드: [의사코드](의사코드.md)

## 1. 기능 목록

| 우선순위 | 뜻 | 기능 |
|---|---|---|
| **Must Have** | 없으면 안전하게 검수할 수 없다 → **반드시** | 아래 §2 |
| Should Have | 있으면 작업이 훨씬 편하다 | 저장 후 다음 · Undo · 단축키 · REVIEW/EDITED 만 보기 · Scene Type |
| Optional | 핵심이 안정된 뒤에만 | BBox 이동·크기 조절 · Diff View · Polygon · Auto Label |

> 시간이 부족하면 **Optional 부터 포기하고 Must Have 와 검증(QA)을 지킵니다.**

## 2. Must Have 기능

| 구분 | 기능 | 한 줄 설명 | 만드는 날 |
|---|---|---|---|
| 보기 | 이미지 열기 | 사진 선택해서 화면에 표시 | 1일차 |
| 보기 | 파일명 표시 | 지금 어떤 사진인지 | 1일차 |
| 보기 | Fit (화면에 맞춤) | 전체가 한눈에 보이게 | 1일차 |
| 보기 | 이전 / 다음 | 앞뒤 사진으로 이동 | 2일차 |
| 보기 | Zoom / Pan | 작은 이물을 확대해서 확인 | 2일차 |
| 라벨 | **같은 이름 TXT 자동 불러오기** | 사진을 열면 TXT 를 알아서 읽음 | 1일차 |
| 라벨 | 기존 BBox 표시 | 이미 있는 라벨을 사진 위에 그림 | 1일차 |
| 라벨 | 새 BBox | 빠진 이물을 드래그로 추가 | 1일차 |
| 라벨 | 선택 / 삭제 | 틀린 BBox 를 고르고 지움 | 1일차 |
| 라벨 | Class 지정 / 변경 | 0~6 중 선택, 틀린 Class 수정 | 1일차 |
| 라벨 | 여러 BBox | 한 사진에 여러 개 | 1일차 |
| 저장 | WORK 에 저장 | 수정 결과를 YOLO TXT 로 저장 | 1일차 |
| 저장 | **다시 불러오면 같은 위치** | 저장한 BBox 가 그대로 복원 | 1일차 |
| 저장 | **원본(RAW) 안 건드림** | 원본 파일은 절대 수정 안 함 | 1일차 |
| 저장 | 저장 안 한 변경 경고 | 실수로 닫아도 작업이 안 날아가게 | 1일차(기본) |
| 기록 | PASS / EDITED / REVIEW | 검수 상태 기록 | 2일차 |
| 기록 | 작업자 · 메모 → Manifest | 누가 무엇을 했는지 | 2일차 |

## 3. 화면 설계 (1일차 시제품)

```text
┌──────────────────────────────────────┬───────────────┐
│ [열기] [저장] [다시 불러오기] [삭제]   │ 클래스 선택    │
├──────────────────────────────────────┤ (0~6)         │
│                                      ├───────────────┤
│        이미지 + BBox                  │ 라벨 목록      │
│                                      │ (BBox 목록)    │
├──────────────────────────────────────┴───────────────┤
│ 상태줄 : 파일명 · 원본 좌표 · 안내 메시지                │
└──────────────────────────────────────────────────────┘
```

| 화면 요소 | 하는 일 |
|---|---|
| 위쪽 버튼 4개 | 열기 / 저장 / 다시 불러오기 / 선택 BBox 삭제 |
| 가운데 이미지 | 사진과 BBox 를 함께 표시, 드래그로 BBox 추가 |
| 오른쪽 위 클래스 | 0~6 선택 (색으로 구분) |
| 오른쪽 아래 라벨 목록 | 지금 사진의 BBox 목록 |
| 아래 상태줄 | 안내, 마우스가 가리키는 원본 좌표 |

## 4. 프로그램 기본 흐름

```text
이미지 열기
        ↓
같은 이름 TXT 자동 Load
        ↓
BBox 표시
        ↓
수정 / 추가 / 삭제
        ↓
저장 (WORK)
```

## 5. 가장 중요한 약속

```text
BBox 는 "원본 이미지 픽셀 좌표"로 기억한다
        ↓
화면에 그릴 때만 배율을 곱한다
        ↓
저장할 때만 YOLO 비율값으로 바꾼다
        ↓
그래서 화면 크기가 바뀌어도 BBox 는 같은 객체 위치에 남는다
```

## 6. 일차별 구현 계획

```text
1일차   사진 1장: 열기 → TXT → BBox → 추가/삭제/Class → 저장 → 다시 불러오기
        ↓
2일차   이전/다음, Zoom/Pan, 검수 상태·작업자·메모
        ↓
3일차   자동 검사(Validation), Manifest, 20~50장 시험
        ↓
4~5일차  900장 검수 · 교차검수 · 최종 확정
```
