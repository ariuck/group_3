# 5. 1장 End-to-End 실행 계획

> **End-to-End = 처음부터 끝까지 한 번 이어서 돌려 보는 것.** 사진 **딱 1장**으로 프로그램의 뼈대가 맞는지 확인합니다.
> 1장에서 끝까지 돌아가야 2일차에 기능을 늘릴 수 있습니다.

## 1. 실행 순서

```text
① 사진 1장을 연다
        ↓
② 같은 이름 TXT 가 자동으로 읽히고 BBox 가 보이는가?
        ↓
③ BBox 를 하나 추가한다 (또는 삭제 / Class 변경)
        ↓
④ 저장한다 → WORK 폴더에 TXT 가 생기는가?
        ↓
⑤ [다시 불러오기] → 같은 위치에 BBox 가 다시 나타나는가?
        ↓
⑥ 원본(RAW) TXT 는 그대로인가?
```

실행 방법:

```text
python main.py
```

→ [📂 이미지 열기] → 사진 선택

## 2. 성공 기준 (6개 모두 O 여야 통과)

| 확인 | 샘플 시험 (가짜 이미지) | 내 사진 |
|---|:-:|:-:|
| 이미지가 정상으로 보인다 | O | 【O/X】 |
| TXT 줄 수 = 화면 BBox 수 | O (2 = 2) | 【O/X】 |
| BBox 가 객체 위치에 맞다 | O | 【O/X】 |
| 추가한 BBox 가 WORK 에 저장된다 | O (2줄 → 3줄) | 【O/X】 |
| 다시 불러오면 같은 위치에 복원된다 | O (3개 복원) | 【O/X】 |
| 원본 TXT 가 안 바뀐다 | O (원래 2줄 그대로) | 【O/X】 |

## 3. 실패하면 먼저 볼 곳

| 증상 | 먼저 확인 |
|---|---|
| TXT 가 안 보인다 | 사진·TXT 파일 이름이 같은지, 폴더가 `images/` ↔ `labels/` 인지 |
| BBox 가 어긋난다 | 비율 → 픽셀 변환 → 화면 배율/위치 계산 순서로 |
| 저장했는데 사라진다 | WORK 저장 위치, 저장 성공 메시지 |
| 다음 사진에 이전 BBox 가 남는다 | 사진을 바꿀 때 BBox 목록을 비우는지 |
