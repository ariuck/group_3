# 2일차 역할 분담 — 라벨링 프로그램 핵심 기능 완성

> 2일차 목표: **한 장에서 되던 것을 실제 라벨링 도구로 확장한다.**
> `한 장 성공 → 여러 이미지 탐색 → 여러 BBox → Class 편집 → Zoom/Pan → 안전한 Save/Reload`
>
> 담당자 이름은 팀이 정해서 `【이름】` 에 적습니다. 역할은 1일차 역할 5개를 그대로 씁니다.

## 1. 어제 끝난 것 / 오늘 할 것

| 구분 | 기능 |
|---|---|
| ✅ 이미 있음 | 이미지 1장 열기 · 같은 이름 TXT Load · BBox 추가·선택·삭제 · Class 변경 · WORK 저장 · 다시 불러오기 · RAW 저장 거부 · 데이터 조사 · **저장 시 검수표(CSV) 자동 기록** |
| ⬜ 오늘 만들 것 | **이전/다음 이동 · 폴더 열기 · Zoom/Pan · 저장 안 한 변경 보호(이동 시) · 상태·작성자·검수자 입력 · Validation · Undo(권장) · Golden Sample 시험** |

### ② GUI / 이미지 — 【이름】  ★ 이동 기능
| 할 일 | 완료 기준 |
|---|---|
| **폴더 열기** — `data/raw` 의 모든 JPG 를 데이터셋 → split → 파일명 순으로 목록화 | 900장이 목록에 나온다 |
| **이전 / 다음** 버튼과 단축키(`A`/`D`, 방향키), 첫/마지막 경계 처리 | 20장 이상 연속 이동해도 멈추지 않는다 |
| **진행률 `125 / 900`** 과 파일명, 출처(데이터셋/split) 표시 | 이동할 때마다 숫자가 맞다 |
| **이동 시 상태 초기화** — 이전 이미지의 BBox 가 다음 이미지에 남지 않는다 | 연속 이동 시험 통과 |
| 새 파일 `src/ui/navigator.py` (목록·현재 위치·이전/다음) | 화면 코드와 분리된 순수 로직 |
| *(권장)* **`수정 필요`만 보기 / `수정 완료`만 보기** 필터 — 검수표의 상태를 읽어서 걸러 보기 (④ 의 상태 기록 후 가능) | 필터를 켜면 해당 사진만 이동 |
| *(선택)* 단축키 정리: 이동 `A`/`D`, 저장 `Ctrl+S`, 저장 후 다음 `W`, Class `0~6`, 삭제 `Delete`, Undo `Ctrl+Z` | 화면에 단축키 안내 |

### ③ BBox / 좌표 — 【이름】  ★ Zoom/Pan
| 할 일 | 완료 기준 |
|---|---|
| **Fit / Zoom In·Out / Pan**, 현재 배율 표시 (휠 확대, 우클릭 또는 Pan 버튼으로 이동) | 4K 이미지에서 작은 이물을 확대해 볼 수 있다 |
| **확대한 상태에서 BBox 작성** | `확대 → BBox 작성 → 원래 배율 → 같은 객체 위치` |
| 화면↔원본 좌표 변환을 한 곳으로 — 새 파일 `src/bbox/viewport.py` | Zoom/Pan 후에도 BBox 가 움직이지 않는다 |
| **Undo (Ctrl+Z)** — 권장 | 마지막 추가/삭제/Class 변경 취소 |

> 렉 주의: 이미지를 다시 줄이는 일(무겁다)과 BBox 를 다시 그리는 일(가볍다)을 분리하고, 휠 연타는 묶어서 한 번만 그린다. (1일차 렉 수정 내용 참고)

### ④ 라벨 저장 / 데이터 — 【이름】  ★ 저장·상태
| 할 일 | 완료 기준 |
|---|---|
| **저장 안 한 변경 보호** — 이동·종료 시 경고, **저장 실패하면 이동하지 않는다** | 수정 후 `다음` 을 눌러도 작업이 유실되지 않는다 |
| **저장 후 다음** (`W` / 버튼) | 저장하고 바로 다음 이미지 |
| **상태·작성자·검수자·비고 입력칸** → 저장할 때 검수표(CSV) 사람 칸에 기록 (`src/manifest/manifest_writer.py` 확장) | 검수 완료·수정 필요·제외를 화면에서 고를 수 있다 |
| **이미지 유형**(김치+대상 객체 / 정상 김치 / 대상 객체 단독 / 판단 어려움) 선택과 **발견된 문제** 입력 — REVIEW 는 `REVIEW: 이유 코드` | 검수표 `이미지 유형`, `발견된 문제` 칸에 기록 |
| 사람이 정한 상태·입력한 값을 프로그램이 덮어쓰지 않는지 확인 | 기존 자체 점검 통과 유지 |
| **Save → 다른 이미지 → 돌아오기 → 복원** 확인 | 수정한 BBox 가 그대로 복원 |

### ⑤ QA / 검증 — 【이름】  ★ Validation·시험
| 할 일 | 완료 기준 |
|---|---|
| **Validation 본체** (`src/validation/validator.py` 확장): 짝 없음, TXT 형식, Class 범위, **Class 4**, 좌표 범위, BBox 경계 밖, 중복 BBox, Empty TXT | 자동으로 고치지 않고 **파일명과 오류를 기록**만 한다 |
| 화면의 **[Validation] 버튼**과 결과 창 | 누르면 결과 표가 나온다 |
| **Golden Sample 20장 선정** — 데이터셋 3곳(학습데이터1/train, 2/train, 2/validation)과 BBox 1개·여러 개·작은 객체·가장자리 객체를 섞는다. **사람이 먼저 라벨을 눈으로 확인해 문제 없는 것만** 기준(Reference)으로 지정한다 | 선정 목록 |
| Golden 시험은 **프로그램의 Load/Save 가 라벨을 망가뜨리지 않는지** 보는 것이다 (모델 평가가 아님). 저장 **전후 TXT 의 좌표·Class 를 비교**한다 | 비교 결과 기록 |
| **Golden Test 실행·기록** (`reports/test_report.md` 의 1장) | 항목별 PASS/FAIL |
| 오류 발견 시 **이슈 기록** (무엇이·원인·수정·재시험) | `docs/day2/2일차_기록.md` |

## 5. 기능 간 약속 (인터페이스)

서로 기다리지 않도록 아래 이름으로 만들기로 먼저 약속합니다.

| 만드는 사람 | 약속 |
|---|---|
| ② `ImageNavigator` | `items`(목록), `index`, `current()`, `next()`, `prev()`, `position_text()` → `"125 / 900"` |
| ③ `Viewport` | `scale`, `offset`, `fit(w, h, img_w, img_h)`, `zoom_at(factor, cx, cy)`, `pan(dx, dy)`, `to_screen(x, y)`, `to_image(sx, sy)` |
| ④ 저장 | `save()` 는 성공하면 `True`, 실패하면 `False` — ② 의 이동 기능은 `False` 이면 이동하지 않는다 |
| ⑤ `validate_dataset(...)` | 오류 목록 `[{파일, 종류, 내용}, ...]` 을 돌려준다 |

## 9. 오늘 하지 않는 것

- BBox **이동·크기 조절**(드래그로 옮기기) — 2일차에서는 필수가 아닙니다. 잘못된 BBox 는 **삭제 후 다시 그리기**로 고칩니다.
- Pilot Test(20~50장), 900장 본 작업 — 3일차 이후
- 가이드는 Validation 완성과 Manifest 를 3일차에 두지만, GUI 기능표에서 필수이므로 오늘 **기본 동작**까지 만들고 3일차에 안정화합니다.
