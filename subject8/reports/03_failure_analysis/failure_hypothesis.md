## 3. 원인 가설 (영향이 큰 순서)

### H1. 작은 이물을 놓친다 — MODEL/TRAIN (입력 해상도)

| 근거 | 내용 |
|---|---|
| 건수 | FN 111 중 **83건**이 `small_object`. 플라스틱 FN 64 중 58건이 150px 미만 |
| 크기 | 플라스틱 FN 중앙값 **73px**. 원본 4848px 을 640 으로 줄이면 1/7.6 → 약 **10px** (검출층 stride 8 격자 1~2칸) |
| 크기별 Recall | 플라스틱 작은 것 0.61 ↔ 중간 0.84 (같은 Class 안에서 크기만 다른데 차이) |
| Class 틀림 | CLASS_ERROR 35 중 17건도 `small_object` — 작은 플라스틱을 벌레(11)·갈변(4)으로 읽음. 특징이 사라져서 틀린 것으로 보인다 |

- **원인 추정**: 작은 물체의 특징이 입력을 줄이는 과정에서 사라진다.
- **대응**: `imgsz` 640 → 1280 → 1920 (그 뒤 2240 · 2560). 나머지 조건은 그대로 → exp001 · exp002.
- **이후 검증 — 맞았다.** Val mAP50-95 0.470 → 0.646 (1280) → 0.704 (1920). 같은 Class 의 mAP50-95: 플라스틱 **0.457 → 0.845** · 가지 0.538 → 0.897 · 벌레 0.463 → 0.873 (Final 후보 B 의 seed 5개 평균, 해상도와 함께 모델 11s · 증강도 달라진 값이라 해상도만의 효과는 아니다). 해상도를 1920 에서 1280 으로 내리면 0.680 으로 -0.044 (exp012). 2560 은 B 보다 낮았다 → 해상도는 2240 근처에서 포화.
- **사람 확인 필요**: 플라스틱 FN 57건이 G05 에 몰린 이유 (G05 의 플라스틱이 유난히 작은가, 소품 종류인가). 분포 표만으로는 알 수 없다.

### H2. Validation 갈변은 Train 갈변과 다른 물체다 — DATA (분포 차이)

| 근거 | 내용 |
|---|---|
| 박스 크기 | Train 갈변 209개 중앙값 **211px** ↔ Val 갈변 15개 중앙값 **23px** (Val/Train = **0.11**). 다른 Class 는 0.47~2.3 배 |
| 결과 | 15개 전부 FN (Recall 0), 전부 150px 미만. 12개 G13 · 3개 G05 |
| 학습 데이터 | Train 갈변은 대부분 잎 전체가 변한 것 (kimchi_v5_split.md · baseline_vs_improved.md 한계 참고), Val 은 작은 반점 |
| 해상도로 못 푸는 이유 | 640 에서 23px → 약 3px. 1920 에서도 약 9px. 그런데 Train 에는 그 크기의 예가 거의 없다 |

- **원인 추정**: 해상도 문제(H1)가 **겹쳐** 있지만, 더 근본은 Train 에 작은 반점 예시가 거의 없다는 것.
- **대응**: ① 해상도 (exp001~) ② 타일링 (exp004) ③ 4라운드: 반점 복제 · 합성 · Train 반점 복원 · 2560 (각 seed 5개) ④ 5라운드: P2 검출층 · 변형 합성 (Final 뒤 exp063 1회).
- **이후 검증 — 데이터를 늘리는 학습 기법으로는 고쳐지지 않았고, 구조 변경은 1회에서 효과가 보였다.** 갈변 mAP50-95: Baseline 0.000 → 1920 타일링 0.08 → B(2240) 평균 **0.108**, 4라운드 6방향 모두 0.075~0.111 (B 와 같은 범위). Frozen Test 에서는 Recall 0.00 · mAP50-95 0.007. 5라운드 사전 진단 ([`experiment_handoff.md`](../../docs/project/experiment_handoff.md) 10장): 반점 20~31px 13개 중 9~10개는 confidence 0.001 에서도 **예측 박스 자체가 나오지 않는다** (후보 단계에서 사라짐). **추가 (10-20 오후)**: 그 진단대로 P2 검출층 + 변형 합성(exp063, seed 1개)을 학습하자 Val 갈변 0.107 → 0.237, 반점 15개 중 14개에 후보가 생겼다 — 분포 차이(이 가설)에 검출 격자 크기 문제가 함께 작용했다는 근거다. 다만 다른 Class 가 떨어져 전체는 0.725 (같은 seed B 0.746).
- **판정**: "Train 과 Val 의 갈변이 다른 물체"라는 가설과 모든 결과가 맞는다. 다만 **확정은 아니다** — Val 갈변이 15개뿐이라 박스 1개가 Recall 6.7%p 를 움직이고, 같은 기준으로 라벨링한 작은 반점 데이터를 넣어 보는 실험은 하지 않았다. 그 실험이 결론을 내릴 수 있다 (교과 14 과제).

### H3. Validation 나뭇잎·종이는 Train 과 크기·모습이 다르다 — DATA (분포 차이)

| 근거 | 내용 |
|---|---|
| 박스 크기 | Train 308개 중앙값 136px ↔ Val 192개 중앙값 **313px** (Val/Train **2.31**) — 평가 쪽이 2배 이상 크다 |
| 결과 | FN 23건 **전부 G13**, 중앙값 238px (작은 물체 문제가 아님). 잎 → 플라스틱 10 · 잎 → 가지 2 로 틀리기도 함 |

- **원인 추정**: Train 은 작은 잎·종이 조각 위주, Val(G13)은 큰 마른 잎 위주라 모습이 다르다.
- **대응**: 별도 대응을 정하지 않았다 (H1 의 해상도·모델 변경에 같이 따라감).
- **이후 검증 — 가설이 예상한 것과 다르게 나왔다.** "재학습으로는 안 고쳐진다"고 추정했지만 Class 0 mAP50-95 는 0.657 → **0.840**(B 평균)으로 크게 올랐다. 해상도·모델·증강이 큰 잎에도 도움이 됐다는 뜻이다 (왜인지는 이 자료로 알 수 없다). 다만 **Frozen Test 에서 Class 0 Precision 이 0.37** 로 낮아, 놓치는 문제가 오검출 문제로 바뀌었다 (정답 23개에 대해 오검출이 많음).
- **사람 확인 필요**: Test 에서 잎·종이로 잘못 찾은 박스가 실제로 무엇인지.

### H4. 같은 물체에 박스가 겹쳐 나온다 — INFERENCE (추론 설정)

| 근거 | 내용 |
|---|---|
| 건수 | FP 87 중 **63건(72%)** 이 정답과 겹치는 박스 — FP_DUPLICATE 30 (정답과 IoU 중앙값 0.79, 이미 맞춘 물체의 두 번째 박스) + FP_PARTIAL 33 |
| Class | 두 종류 모두 플라스틱이 가장 많다 (16 · 20) |

- **원인 추정**: Ultralytics 기본 NMS 는 **Class 별로** 겹친 박스를 지운다. Class 가 헷갈리는 물체는 박스가 두 개 남는다.
- **대응**: 추론 때 `agnostic_nms=True` 를 Validation 에서 비교 (재학습 없음, [`15_eval_inference_options.py`](../../scripts/15_eval_inference_options.py)).
- **이후 검증 — 맞지 않았다.** Final 후보 모델(exp007 · exp008, 11s)에서 기본 0.731 → agnostic NMS **0.715** (-0.016) · TTA 0.716. 더 낮아져서 쓰지 않았다 ([`../04_improvement/inference_options.csv`](../04_improvement/inference_options.csv)). 단 이 비교는 **Baseline 이 아니라 11s 모델**에서 했다. Baseline 의 FP_DUPLICATE 가 같은 이유(Class 혼동)인지는 확인하지 않았다.

| 근거 | 내용 |

- **사람 확인 필요**: G05 에서 20건이 몰린 이유와 **빠진 라벨이 없는지** — `python scripts/09_collect_failures.py` 가 `demo/failure_analysis/` 에 만드는 대표 실패 사진(사진 PC 에서 다시 생성)이나 `failure_analysis.csv` 의 `FP_BACKGROUND` 행 좌표로 24건을 눈으로 확인. 빠진 라벨이면 GT 수정 → Dataset Version 변경 사안이다.
