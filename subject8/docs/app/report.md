# `subject8/app/report.py`

> 시연 프로그램의 **보고서 만들기** — 시연 결과를 HTML 한 파일로 만든다. 브라우저에서 미리보기 · 저장 · 인쇄(PDF). 서버 디스크에는 저장하지 않는다.

[← 코드 문서 목차](../README.md) · [코드 보기](../../app/report.py)

## 사용법

시연 화면의 **⑥ 보고서 만들기** 버튼(또는 오른쪽 위 *보고서 만들기*, 단축키 `R`). ⑤ 전체 채점이 끝나면 완료 창에서 바로 만들 수 있다.

| 선택 | 뜻 |
|---|---|
| 확신도 기준 | 보고서의 판정 기준 (기본: 지금 화면의 기준) |
| 시연자 | 머리말에 적을 이름 (선택) |
| 틀린 박스 목록은 Validation 전체로 | 끄면 시연에서 본 사진에서만 모은다 |
| 틀린 박스의 사진 조각 넣기 | 박스 주변을 잘라 넣는다 (최대 80개) — **회사 사진이라 외부 공유 금지** 경고가 보고서 맨 위에 들어간다 |

서버 쪽은 `POST /api/report` (JSON `{conf, viewed, crops, all, presenter}`) → `build_report()` → HTML.

## 보고서 내용

| 장 | 내용 |
|---|---|
| 1. 요약 | Frozen Test · Validation mAP50-95, 찾은 비율 · 맞은 비율, 맞힘 · 종류 틀림 · 오검출 · 놓침, 모델 · 데이터 · 실행 장치 |
| 2. 확신도 기준별 | 0.05 ~ 0.95 에서 찾은 비율 · 맞은 비율 · F1 그래프(SVG)와 표, 이번 기준 · F1 최고 기준 표시 |
| 3. Class 별 | 정답 · 예측 · 맞힘 · 놓침 · 오검출 · 찾은 비율 막대 |
| 4. 본 사진 | 시연 중에 연 사진과 그 결과 |
| 5. 틀린 박스 | 놓침 → 종류 틀림 → 오검출 순, Class · 확신도 · 크기(px) · 사진 · 묶음 (선택: 사진 조각) |
| 6. 읽는 법 · 한계 | 판정 규칙, 박스 개수 기준(mAP 아님), 공식 성능은 Frozen Test, 갈변 · 정상 김치 한계 |

인쇄하면 A4 에 맞게 나뉜다 (5장은 새 쪽에서 시작).

## 주의사항

- 숫자는 `Demo.judge` = [`src/inference.py`](../src/inference.md) 의 `match()` (IoU 0.5) 그대로라 `08` · `09` 와 같다. **박스 개수 기준**이라 mAP 와 다르다.
- 전체 채점을 하지 않았으면 보고서 1장에 "본 사진만 담았다"는 경고가 들어간다.
- 사진 조각을 넣은 보고서는 Git · 외부에 올리지 않는다 (파일 이름 끝에 `_사진포함`).
