# 발표자료 편집·연출 검토 (2026-10-20)

실제 외부 전문가의 심사나 인증이 아닌, AI 검토자 관점의 편집 검토입니다.

## 반영한 판단
- 본편은 18장 유지. 전달 순서: 데이터 품질 → 평가 분할 → 개선·선택 → 한계 → 후속 진단 → 시연·인계.
- 각주 원문은 발표자 노트에 보존하고, 화면에는 비교 조건과 출처 핵심만 남김.
- 복원 실험은 라벨 삭제의 원인 여부를 확정하지 않음. P2 가중치 초기화는 원인 후보로 표기.
- seed 반복은 통계적 유의성이나 작은 Val의 독립성을 보장하지 않음. +0.02는 사전 실용 기준.
- 큰 차트는 자동 등장. 다음 키가 추가 단계를 요구하지 않으므로 리허설 흐름을 유지.
- 포인터·행 강조·카드 집중·실험 방향 비교를 선택적으로 사용. 효과 끄기와 reduced-motion·인쇄 지원.

## 리허설
- 목표 발화 시간은 750초(12분 30초), 7회 전환 70초를 합해 약 13분 40초. 실제 시간은 6인 리허설로 확인.
- 시연 85초 포함. 프로그램은 이 PC에서 직접 실행하고 저장된 비교 사진으로 대비.
- Q&A에서 실험 수치를 검토할 때 11번 비교 버튼과 A10을 사용. 본편에서 부록 내용을 모두 읽지 않음.

## 독립 AI 검토자 2인의 의견과 반영

외부 인간 전문가의 평가·인증이 아니다. 두 AI 검토자가 로컬 HTML 본문·노트·Q&A를 읽고 편집 관점과 기술 타당성 관점에서 의견을 냈다. 실험 원본과 실제 현장 성능을 검증한 평가는 아니다.

| 관점 | 핵심 의견 | 반영 |
|---|---|---|
| 발표 편집 | 10~12장 반복과 긴 각주가 핵심을 가림 | 개선 폭 / 선택 기준 / 인사이트로 역할 정리, 자세한 조건은 노트로 |
| 발표 편집 | 6인 전환·시연에 시간 여유 필요 | 발화·시연 목표 12:30, 전환 포함 13:40으로 재배분 |
| 발표 편집 | Q&A가 운영 설명으로 끝남 | 데이터·최종 평가·후속 과제의 3개 결과로 마무리 |
| 기술 타당성 | seed 5개는 유의성 보장이 아님 | 근거 없는 0.013 식별 보장 삭제, 실용 채택 기준임을 명시 |
| 기술 타당성 | 복원 실험으로 삭제 영향 배제 불가 | 결과 관찰과 인과 추정 분리 |
| 기술 타당성 | P2 초기화와 성능 하락의 원인 확정 불가 | 구조·합성·batch 동시 변경 한계, 가중치 이식 범위는 가설로 표기 |
| 기술 타당성 | Test 사전 열람과 정식 평가 구분 | '처음 보는 Test' 표현 삭제, 본편 각주·부록 이력 유지 |
