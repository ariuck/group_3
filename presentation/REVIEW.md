# 발표자료 편집·연출 검토 (2026-10-20)

실제 외부 전문가의 심사나 인증이 아닌, AI 검토자 관점의 편집 검토입니다.

## 반영한 판단
- 본편은 18장 유지. 전달 순서: 데이터 품질 → 평가 분할 → 개선·선택 → 한계 → 후속 진단 → 시연·인계.
- 각주 원문은 발표자 노트에 보존하고, 화면에는 비교 조건과 출처 핵심만 남김.
- 복원 실험은 라벨 삭제의 원인 여부를 확정하지 않음. P2 가중치 초기화는 원인 후보로 표기.
- seed 반복은 통계적 유의성이나 작은 Val의 독립성을 보장하지 않음. +0.02는 사전 실용 기준.
- 큰 차트는 자동 등장. 다음 키가 추가 단계를 요구하지 않으므로 리허설 흐름을 유지.
- 포인터·행 강조·카드 집중·실험 방향 비교를 선택적으로 사용. 효과 끄기와 reduced-motion·인쇄 지원.

## 리허설
- 목표 발화 시간은 750초(12분 30초), 7회 전환 70초를 합해 약 13분 40초. 실제 시간은 6인 리허설로 확인.
- 시연 85초 포함. 프로그램은 이 PC에서 직접 실행하고 저장된 비교 사진으로 대비.
- Q&A에서 실험 수치를 검토할 때 11번 비교 버튼과 A10을 사용. 본편에서 부록 내용을 모두 읽지 않음.
