## 3단계 · YOLO TXT 이해

TXT 한 줄 = 객체 1개. 순서: `class  x_center  y_center  width  height` (모두 **0~1 비율값**)

**직접 풀어 본 예** (샘플 이미지 3840×2160, TXT 첫 줄):

```text
2  0.7565104167  0.1622685185  0.0473958333  0.0615740741
```

| 계산 | 값 |
|---|---|
| Class | **2** = 나뭇가지류 |
| 중심 x 픽셀 = 0.7565 × 3840 | 2905 |
| 폭 픽셀 = 0.0474 × 3840 | 182 |
| 왼쪽 x1 = 2905 − 182/2 | **2814** |
| 중심 y 픽셀 = 0.1623 × 2160 | 350.5 |
| 높이 픽셀 = 0.0616 × 2160 | 133 |
| 위쪽 y1 = 350.5 − 133/2 | **284** |

→ 프로그램의 라벨 목록에 `[2814, 284, 182, 133]` 로 나온 값과 **같다** (좌표 변환이 맞다는 확인)

| 알게 된 것 | |
|---|---|
| 한 줄 = 객체 1개 | TXT 가 3줄이면 BBox 3개 |
| 비율값 → 픽셀 | `픽셀 = 비율 × 이미지 크기` |
| TXT 는 **이미 만들어진 정답 후보** | 처음부터 그리는 게 아니라 **검수·보정** |
| 빈 TXT | 오류가 아니라 **정상 김치(이물 없음)** 일 수 있다 |
| 내가 풀어 본 줄 | 【내 칸】 |

## 4단계 · 샘플 사진 몇 장 먼저 보기

(자동 선정 없이 **직접 열어 본 사진 3~5장**이면 충분합니다)

| 보는 사진 유형 | 확인 질문 | 결과 |
|---|---|---|
| 김치 + 대상 객체 | TXT 줄 수 = BBox 수? 위치·Class 맞나? | 【내 칸】 |
| 정상 김치 | BBox 가 없는데 정말 이물이 없나? | 【내 칸】 |
| 대상 객체 단독 | 김치가 없어도 BBox · Class 가 맞나? | 【내 칸】 |
| Empty TXT / Class 4 | 보이면 **삭제하지 말고 기록(REVIEW)** | 【내 칸】 |

(예시, 가짜 샘플 3장 — 산출물 §1-2 참고) 김치+대상 1장 · 정상 김치 1장 · 대상 단독 1장을 열어 TXT 와 대조했고, 정상 김치의 빈 TXT 는 오류가 아님을 확인했다.

> 알게 된 것: **정상 김치도, 대상 단독 사진도 지우지 않는다.** 이유는 모델이 "없을 때 없다고 하는 것"도 배워야 하고, 분포는 교과 8 에서 따로 보기 때문.

## 5단계 · 기준선 확정

| 정한 것 | 내용 |
|---|---|
| Class | **0~6 그대로**, 번호 바꾸기 금지, **4번은 사용 안 함** |
| 김치 | Class 가 아님 → BBox 안 그림 |
| BBox | 5가지 약속 (전체 포함 · 경계에 가깝게 · 객체마다 따로 · 작아도 누락 금지 · 애매하면 REVIEW) |
| 상태 | PASS(맞음) / EDITED(고침) / REVIEW(애매함) |
| 기록 | Manifest 에 출처 · 장면 유형 · 작업자 · 상태 · 메모 |
| 결과 | [1일차 산출물 §2 · §3](산출물_요약.md) |

## 오늘 꼭 이해할 3가지

```text
1. 김치는 라벨링 대상 Class 가 아니다 (제공된 Class 0~6 객체만 확인)
        ↓
2. 정상 김치 사진은 빈 TXT 가 정답일 수 있다 (이물이 없으면 BBox 가 없어도 된다)
        ↓
3. 대상 객체 단독 사진도 검수 대상이다 (김치가 없어도 BBox 와 Class 를 확인)
```
