# `tools/share_server.py`

> 같은 와이파이/랜 안에서 결과 zip 을 **내려받고 올리는 임시 웹 서버**. 표준 라이브러리만 쓰며, 검수자·PM 단계별 가이드 화면과 어떤 파일이든 주고받는 **공용 보관함**(한 개 최대 20GB)이 함께 들어 있다.

[← 코드 문서 목차](../README.md) · [코드 보기](../../tools/share_server.py)

## 사용법

```bash
py tools/share_server.py --dir C:\공유              # Windows
python tools/share_server.py --dir ~/share           # 그 밖의 환경
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--dir` | Windows `C:/공유`, 그 밖 `~/share` | 공유 폴더 |
| `--port` | 8000 | |
| `--host` | `0.0.0.0` | 이 PC 안에서만 시험하려면 `127.0.0.1` |
| `--max-mb` | 50 | 올릴 수 있는 zip 최대 크기 |
| `--cloud-max-gb` | 20 | 공용 보관함에 올릴 수 있는 파일 한 개의 최대 크기 |
| `--minutes` | 120 | 이 시간이 지나면 저절로 꺼짐 (`0` 이면 끄지 않음) |
| `--assign` | `김동훈:1-300,이후영:301-500,지혜성:551-900` | 검수자별 번호 범위 ([team/검수_배정](../project/team/검수_배정.md)) |

다른 PC 는 브라우저로 `http://<서버 PC 주소>:8000` 에 접속해 콘솔에 나온 **4자리 번호**를 입력한다. 주소 뒤에 `/#cloud` 를 붙이면 공용 보관함 탭이 바로 열린다.

### 폴더 구조 (`--dir` 아래)

```
보내기/            PM 이 내놓는 zip (다른 PC 가 내려받음)
받은결과/          다른 PC 가 올린 zip
받은결과/풀림/     올라온 zip 이 자동으로 풀린 곳 → import_labels · merge_manifests 에 그대로 넣음
보관함/            공용 보관함 — 누구나 올리고 내려받는 파일 (종류 제한 없음, 서버를 꺼도 남음)
보관함/휴지통/     보관함에서 지운 파일이 옮겨지는 곳 (목록에 안 보임, 완전히 지우지 않음)
```

## 웹 화면 (`PAGE`)

| 탭 | 내용 |
|---|---|
| 검수자 가이드 | 이름·터미널(WSL/PowerShell) 선택 → 0~7단계 (최신 도구 받기 → 파일 받기 → 풀기 → 내 검수표 치우기 → 명령 2개로 가져오기 → 검수 → 내 범위 묶기 → 올리기). 명령이 이름·터미널에 맞게 자동으로 바뀌고 복사 버튼이 있음. 완료 표시는 브라우저 `localStorage` 에 기억 |
| PM 가이드 | 전체 흐름, 검수 범위 표, 서버 켜기(방화벽 규칙 포함) → 합치기 → 확인 기준(900줄, 누락 0 등) → 마무리 |
| 파일 받기·올리기 | 4자리 번호 입력 → 내려받기 목록 / 끌어다 놓기 업로드(진행 막대) / 받은 파일 목록. 8초마다 자동 새로고침 |
| 공용 보관함 | 같은 번호로 열림. 어떤 파일이든 끌어다 놓기(여러 개는 차례로) · 진행률·속도·남은 시간 · 올리기 취소 · 이름 찾기 · 받기 · 지우기(휴지통으로). 파일 수·전체 크기·서버 PC 의 남은 공간 표시. 올리는 중에 창을 닫으려 하면 확인 |

번호 칸(`#pinbox`)은 탭 밖에 하나만 있고, '파일 받기·올리기'·'공용 보관함' 탭에서 번호를 아직 넣지 않았을 때만 보인다 (`syncPin`). 번호가 틀렸다는 응답(403·429)이 오면 두 탭 모두 다시 잠긴다 (`lockFiles`).

## 주요 구성요소

| 이름 | 설명 |
|---|---|
| `safe_name(name, any_type=False)` | 폴더 부분·위험 글자·제어 문자 제거. 기본은 `.zip` 이고 120자 이하만, `any_type=True`(보관함)는 종류 상관없이 150자 이하. `CON.txt` 같은 Windows 예약 이름은 앞에 `_` 를 붙임 |
| `unique_path(folder, name)` | 같은 이름이 있으면 시각을 붙여 덮어쓰지 않음 |
| `inspect_zip(path, max_total_bytes)` | `.txt`·`.csv` 만, 절대경로·`..`·드라이브 문자 금지, 최대 5000개, 풀었을 때 크기 제한. `(라벨 수, 검수표 줄 수, 목록)` |
| `unpack_zip(zip_path, dest)` | 경로가 `dest` 밖으로 나가지 않는지 한 번 더 확인하고 풂 |
| `is_local_client(ip)` | 사설망·루프백·링크로컬만 허용 |
| `parse_assign(text)` | `'이름:1-300,…'` → `{이름: [1, 300]}` |
| `list_files(folder, pattern="*.zip")` | 파일 목록 (최신순). 폴더와 `.` 으로 시작하는 임시 파일은 뺌 |
| `ShareServer` | `ThreadingHTTPServer`. 폴더 생성, 페이지에 범위·최대 크기·보관함 경로 주입, `check_pin` (IP 별 실패 횟수, 8번 틀리면 60초 잠금), `cloud_room()` (남은 디스크 − 1GB) |
| `Handler` | `GET /` 페이지, `GET /api/list`, `GET /api/download`, `PUT /api/upload` (임시 파일로 받은 뒤 검사 → 저장 → 풀기) |
| `Handler` (보관함) | `GET /api/cloud/list` (파일·남은 공간·한도), `GET /api/cloud/download`, `PUT /api/cloud/upload` (한도·남은 공간만 검사, 넘치면 413·507), `POST /api/cloud/delete` (휴지통으로 옮김) |
| `Handler._send_file` | 1MB 씩 읽어 보냄. `Range` 요청이면 206 으로 그 부분만 (끊긴 내려받기 이어받기), 범위 밖이면 416 |
| `Handler._receive` | 본문을 1MB 씩 `.up-….part` 임시 파일로 받음. 중간에 끊기면 임시 파일을 지우고 오류 |
| `local_addresses()` | 다른 PC 가 접속할 이 PC 의 사설 IPv4 후보 |
| `main(argv)` | 4자리 번호 생성, 서버 시작, 주소·번호·폴더 안내, 시간이 되면 자동 종료 |

- **사용하는 것**: 표준 라이브러리만 (`http.server`, `zipfile`, `secrets`, `ipaddress` …)
- **사용하는 곳**: 직접 실행, [`tests/test_share_server`](../tests/test_share_server.md). 사용 흐름은 [team/결과_주고받기](../project/team/결과_주고받기.md)

## 주의사항

- **보안 수준은 "같은 사설망 + 4자리 번호" 이다.** HTTP(암호화 없음)이고, 번호가 주소창(`?pin=`)에 들어가 브라우저 기록에 남는다. 잠금은 IP 별 8회/60초라 시간을 들이면 번호를 맞힐 수 있다. 필요한 사람이 모두 받으면 **바로 끈다**.
- 기본 검수 범위 `DEFAULT_ASSIGN` 에 **501~550번이 빠져 있다** (이후영 301-500, 지혜성 551-900). 의도한 배정인지 [team/검수_배정](../project/team/검수_배정.md) 과 맞춰 확인한다.
- 여러 사람이 올린 zip 은 모두 같은 `풀림/` 폴더에 풀린다. 같은 경로의 라벨은 **나중에 올린 것이 덮어쓴다** (그래서 `pack_results --from/--to` 로 각자 범위만 묶는다).
- PM 가이드가 안내하는 `공유시작.bat`·`보관함시작.bat`(보관함용, 8시간 뒤 꺼짐) 은 저장소에 포함되어 있지 않다.
- **보관함은 파일 내용을 검사하지 않는다.** 종류 제한 없이 그대로 저장·전달만 하고 서버가 열거나 실행하지 않는다 (`application/octet-stream` + `attachment` + `nosniff` 로 보내 브라우저도 열지 않고 저장만 함). 번호를 아는 사람은 누구나 지울 수 있으므로 지우기는 휴지통으로 옮기기만 한다.
- 큰 파일도 메모리에 올리지 않는다 (300MB 왕복 시험에서 파이썬 메모리 최대 약 5MB). 다만 서버가 `--minutes` 로 꺼지는 순간 올리던 파일은 끊긴다.
- HTML·CSS·JS 가 파이썬 문자열(`PAGE`) 안에 들어 있다. `__ASSIGN__`, `__MAXMB__`, `__CLOUDMAXGB__`, `__CLOUDDIR__` 자리를 서버가 바꿔 넣는다.
