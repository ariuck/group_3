# 검수 배정 (교차검수 3명)

900장을 이후영 · 지혜성 · 김동훈 3명이 나눠 검수합니다. **작성자와 검수자는 달라야 한다**는 규칙을 지키도록, 모든 범위를 **검수자 본인이 작성한 사진이 없는 곳**으로 나눴습니다.

번호는 프로그램 화면의 `N / 900` 과 같습니다. (데이터셋 → split → 파일명 순) 시작 번호로는 `Ctrl+G` 로 바로 이동합니다.

## 배정 (실제로 진행한 분담)

처음에는 300장씩(1~300 / 301~600 / 601~900)으로 나눌 계획이었고, 진행하면서 아래처럼 나눠 검수했습니다.

| 검수자 | 검수한 번호 | 장수 | 위치 | 작성자 (이 범위의 원래 작업자) | 상태 |
|---|---|---:|---|---|---|
| **김동훈** | 1 ~ 300 | 300 | 학습데이터1 / train | 이후영 120 · 손상우 128 · 강동연 52 | 완료·업로드 |
| **이후영** | 301 ~ 500 | 200 | 학습데이터1 / train | 손상우 60 · 지혜성 140 | 완료·업로드 |
| **김동훈** | 501 ~ 550 | 50 | 학습데이터2 / train | 김석범 50 | **남음** (결과 미업로드) |
| **지혜성** | 551 ~ 600 | 50 | 학습데이터2 / train | 김석범 50 | 완료·업로드 |
| **지혜성** | 601 ~ 900 | 300 | 학습데이터2 / train 120 + validation 180 | 김석범 120 · 김동훈 180 | 완료·업로드 |

- 범위가 겹치지 않고, 1~900 전체가 빠짐없이 들어갑니다. 검수자별로는 김동훈 350장(1~300, 501~550) · 이후영 200장 · 지혜성 350장(551~900)입니다.
- 각자 자기 번호 범위만 보면 됩니다. (김동훈은 두 덩어리)
- 2026-10-07 합친 검수표 기준으로 확인한 배정입니다. 작성자 칸이 바뀌면 다시 확인하세요.
- 합친 결과(2026-10-07 16:51): 작성자와 검수자가 같은 줄 0 · 미처리 REVIEW 0 · Validation 오류 0. 501~550 만 검수 전입니다.

## 검수하는 방법

1. 프로그램을 켜고 **검수자 칸에 자기 이름을 한 번** 씁니다. 다음 사진부터는 빈 칸에 자동으로 채워집니다. (프로그램을 켜 둔 동안만 기억)
2. `Ctrl+G` 로 자기 시작 번호(김동훈 1 · 501, 이후영 301, 지혜성 551)로 이동합니다.
3. 한 장씩 보고 판단합니다.
   - **맞다** → `Enter` (저장하고 다음 사진)
   - **틀렸다** → BBox 를 고치고 `Enter`
   - **애매하다** → `R` 을 눌러 이유를 쓰고 `Enter` (`REVIEW: 이유 코드`, [BBox 기준서](../standards/bbox_guide.md)·[Class 기준서](../standards/class_guide.md) 참고)
4. 자기 번호 범위의 **끝 번호에 도달하면 멈춥니다.** 범위 밖 사진은 열어 보기만 하고 저장하지 마세요.

## 지켜야 할 것

- **자기 범위만 저장하세요.** 모두가 같은 합친 결과에서 시작해서 자기 범위만 바꿔야, 나중에 결과를 합칠 때 서로 덮어쓰지 않습니다.
- **검수 완료 표시는 검수자 칸입니다.** `Enter` 를 누르면 원본과 달라진 사진은 `수정 완료` 로 기록되므로(작성자가 이미 고친 사진 포함), 검수를 마쳤는지는 **검수자 칸에 이름이 있는지**로 확인합니다.
- 검수하지 않고 넘기기만 한 사진은 저장되지 않아서 검수자 이름이 기록되지 않습니다. `W` 나 `Ctrl+S` 로 저장만 해도 이름이 들어가니, **검수를 마친 사진에만 저장**하세요.
- 데이터(txt·검수표)는 **허용된 방법**(USB 등)으로만 주고받습니다. ([라벨 합치기](라벨_합치기.md))

## 시작하기 전 (각자)

합친 결과를 받아서 내 PC 에 넣습니다.

```bash
python tools/import_labels.py 받은폴더 --apply --overwrite        # 라벨(txt) 가져오기 (옛 라벨은 새 것으로 바꾸고, 덮어쓴 파일은 data/backup 에 자동 백업)
```

받은 `dataset_manifest.csv` 로 내 `manifests/dataset_manifest.csv` 를 바꿉니다. (바꾸기 전에 내 파일을 따로 복사해 두세요)

## 끝난 뒤 (결과 모으기)

**1. 각자: 내 검수 범위만, 내 이름을 붙여서 묶습니다.** (사진 번호는 프로그램의 `N / 900` 과 같음)

```bash
python tools/pack_results.py --name 김동훈 --from 1 --to 300       # 김동훈 (501~550 은 --from 501 --to 550 으로 따로)
python tools/pack_results.py --name 이후영 --from 301 --to 500     # 이후영
python tools/pack_results.py --name 지혜성 --from 551 --to 900     # 지혜성
```

`data/share/결과_이름_날짜_시각.zip` 이 만들어집니다. 내 범위의 라벨과 `검수표_이름.csv` 만 들어갑니다. 이 파일을 허용된 방법(공유 폴더·근거리 공유 등)으로 PM 에게 전달합니다.

**이렇게 하는 이유**: 세 명의 zip 을 **한 폴더에 같이 풀어도 서로 겹치거나 덮어쓰지 않습니다.** 검수표 이름이 사람마다 달라서(`검수표_김동훈.csv`) 이름이 같은 CSV 가 생기지 않고, 내 범위 밖의 옛 라벨이 다른 사람이 고친 라벨을 덮어쓰는 일도 없습니다.

**2. PM: 세 zip 을 한 폴더(예: `C:\받은결과`)에 풀고 합칩니다.**

```bash
python tools/import_labels.py /mnt/c/받은결과 --apply --overwrite     # 검수하며 고친 라벨 반영
python tools/merge_manifests.py /mnt/c/받은결과 --apply              # 검수표 3개 + 내 검수표를 하나로
```

- 내 `dataset_manifest.csv` 는 자동으로 함께 합쳐지고, 덮어쓰기 전에 백업이 남습니다.
- 같은 사진이 다르게 적히면(충돌) 검수일이 늦은 줄이 이기고, 화면에 알려 줍니다.
