# `tests/test_step_hold.py`

> 방향키를 누르고 있을 때(반복 입력) 사진을 입력마다 읽지 않고 쌓이지 않는지, 번호 이동과 비동기 읽기가 안전한지 확인한다.

[← 코드 문서 목차](../README.md) · [코드 보기](../../../tests/test_step_hold.py) · 대상: [`src/ui/main_window`](../src/ui/main_window.md) (비동기 사진 이동)

## 실행

```bash
python -m unittest tests/test_step_hold.py      # 화면(Tk) 필요
```

## 시험 내용

| 클래스 | 확인하는 것 |
|---|---|
| `StepHoldTest` | 연속 입력이면 목적지만 읽음 · 손을 떼면 밀린 이동이 계속되지 않음 · 양 끝에서 멈춤 · 미저장 변경은 연속 입력에 한 번만 물음 · 확인창 취소 시 머무름 |
| `JumpToNumberTest` | 번호로 이동 · 범위 밖·이상한 입력 거부 · 확인창 취소 시 번호 유지 · 이동한 사진부터 방향키 계속 |
| `AsyncNavTest` | 사진을 읽는 동안 화면이 반응 · 지나가는 사진은 보였다가 마지막 사진이 이김 · **읽는 동안 편집하면 이동을 취소하고 편집을 지킴** (안전장치) · 버리기를 고르면 이동 계속 · 그 사이 다른 사진을 열면 그것이 이김 · 지나가는 깨진 사진은 건너뜀 · 목적지가 깨지면 오류 후 머무름 · 읽는 중에 닫아도 조용함 |
