## 시험 내용 (`MergeManifestsTest`)

| 묶음 | 확인하는 것 |
|---|---|
| 합치기 | 다른 사진은 합쳐서 정렬·번호 다시 매김 · 똑같은 중복은 조용히 하나로 · 다른 split·데이터셋의 같은 이름은 다른 사진 |
| 충돌 | 검수된 줄 → 늦은 검수일 → 뒤 파일 순 · 먼저 넣은 파일이 뒤의 검수 전 줄을 이김 |
| 입출력 | 폴더 입력 + 입력 파일 불변 · 미리보기는 쓰지 않음 · 기본 출력은 프로그램의 검수표 · 저장할 파일이 있으면 백업 + 기존 줄 유지 · 입력에도 있으면 한 번만 합침 · 출력 경로 기본값 · 기존 대상을 못 읽으면 바꾸지 않고 중단 · 머리글이 다르거나 cp949 면 그 파일 이름을 알림 · 없는 입력 보고 |
| 요약 | 상태별 수와 누락 사진 |
| 출처 바로잡기 | 잘못된 출처는 버리지 않고 RAW 에서 찾아 고침 · 모르는 출처는 보고하고 저장 거부 · 두 곳에 있으면 데이터셋으로 고름 · RAW 에 없어도 출처가 다 적혀 있으면 유지 · 빈 줄 무시 |
